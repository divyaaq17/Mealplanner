# 🍽 Meal Planner

A full-stack web application built using **Node.js, Express.js, MySQL, EJS, and Bootstrap** to help users organize meals, manage recipes, and generate shopping lists.

---

## Features

### Dashboard

* View total dishes
* View total ingredients
* View total meal plans
* Favourite dishes count
* Most planned dish
* Today's meals

### Dish Management

* Add, edit and delete dishes
* Save recipe links
* Search dishes
* Mark dishes as favourites

### Ingredient Management

* Add and delete ingredients
* Prevent deletion of ingredients used in dishes
* Search ingredients

### Daily Meal Planner

* Plan breakfast, lunch and dinner
* Automatically loads saved meals for a selected date
* Update meal plans

### Weekly Planner

* View meals for an entire week
* Organised day-wise display

### Shopping List

* Generates ingredients required for the selected day's meals

### Authentication

* User Login
* User Registration
* Session-based authentication
